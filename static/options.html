Sarashina API

parallax translates with Chrome's on-device translator unless you choose Sarashina in its popup. Sarashina is SB Intuitions' translation API, for English and Japanese in either direction. It translates a paragraph at a time, so the result reads as whole sentences, but links and emphasis inside a paragraph are not kept in the translated pane.

  • When Sarashina is chosen, the text of every page you split is sent to api.sarashina.ai to be translated.
  • The key is stored unencrypted in this browser profile. SB Intuitions advises against using API keys in browser code, so use a key you can revoke.
  • The service accepts requests from Japan only.
